# Optional A8 AI Rematch Prompt

Build a JavaScript-lane PDF report generator in a separate folder named `ai-version`. Use Node.js 22+, Express, the built-in `node:sqlite` module, and Playwright with Chromium. Create an SQLite database with an `orders` table containing id, customer, product, amount, and created_at. Add a repeatable seed script that clears the table and inserts 200 sample orders from six products with amounts between 5 and 200 and dates in the last 30 days.

Implement a `getReportData()` function that returns total order count, total revenue, top five products by revenue using GROUP BY and ORDER BY, and order count/revenue per day for the last seven days. Render an HTML report containing the totals, top five table, daily summary, and all order rows. Use Playwright page.pdf() to create an A4 PDF with print backgrounds, a repeating table header, and `break-inside: avoid` for table rows so no row is split between pages.

Add a reports table with id, path, created_at, report_date, total_orders, and total_revenue. Implement POST /reports to generate the report, save the PDF to disk, insert its metadata, and return 201 with an ID and file link. Implement GET /reports/:id for metadata and GET /reports/:id/file for the actual download. Unknown IDs must return 404. Make repeated POST requests on the same day return the same report ID and link with HTTP 200 instead of creating another PDF. Support `{"force":true}` to bypass the once-per-day check. Keep PDF bytes out of JSON responses. Include setup commands, SQL, test commands, and explain when this synchronous work should move into a background job. Do not silently omit any requirement.
